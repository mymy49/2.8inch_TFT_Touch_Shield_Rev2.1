Detailed Description

LCD driver for the Waveshare 2.8inch TFT Touch Shield (240 x 320, RGB565, SPI interface).

This class specializes ST7789V_spi_with_Brush_RGB565 for the Waveshare 2.8inch Arduino-compatible TFT Touch Shield. It provides the panel-specific power, gamma, and display initialization sequence for the on-board ST7789V controller, and reports the physical resolution of the panel.

Panel Specification

  • Controller : ST7789V
  • Resolution : 240 x 320 pixels (portrait), 320 x 240 pixels (rotated)
  • Color depth: 16-bit RGB565
  • Interface : 4-wire SPI (CS, D/C, RESET, SCK/MOSI)
Note
The touch controller (XPT2046) on the shield is not handled by this class.

Example Usage

#include <2.8inch_TFT_Touch_Shield_Rev2.1/Touch_LCD_Shield_for_Arduino_2_8_inch.h>
Touch_LCD_Shield_for_Arduino_2_8_inch lcd;
void initLcd(void)
{
// SPI peripheral and GPIO output pins must be initialized beforehand.
Touch_LCD_Shield_for_Arduino_2_8_inch::config_t lcdConfig =
{
spi0, // Spi &spi;
{&gpioA, 3}, // pin_t chipSelect;
{&gpioA, 6}, // pin_t dataCommand;
{0, 0} // pin_t reset; (not connected)
};
brush.malloc(5000);
lcd.initialize(lcdConfig);
lcd.setFrameBuffer(brush);
lcd.setBackgroundColor({0xFF, 0xFF, 0xFF});
lcd.clear();
}

Precondition

Deprecated
None.

Stores the SPI/GPIO configuration, applies the SPI specifications for register and pixel transfers, performs a hardware reset, and then sends the panel-specific ST7789V initialization sequence:

  1. Software reset
  2. Memory access control and 16-bit RGB565 pixel format
  3. Gate, VCOM, and power supply voltage settings
  4. Frame rate (60 Hz) and positive/negative gamma correction
  5. Display inversion on, sleep out, and display on
